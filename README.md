# Fake News Detection using Machine Learning

## 📌 Project Description
This project detects whether a news article is **Fake** or **Real** using
Machine Learning and Natural Language Processing techniques.

## 🛠 Technologies Used
- Python
- Pandas
- Scikit-learn
- Flask
- TF-IDF Vectorizer
- Logistic Regression
